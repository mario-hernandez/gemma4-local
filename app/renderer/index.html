Model settings

When enabled, Gemma "thinks out loud" before answering. It reasons step by step internally and then provides a more thorough response. Useful for logic, math, or coding problems. Disable it if you just want quick, direct answers.

1.0

Controls how "creative" or "random" the response is. 0.0 = always the same response, very predictable. 0.3-0.5 = ideal for code and exact data. 0.7-1.0 = natural conversation (recommended by Google: 1.0). 1.5-2.0 = very creative, but may go off track.

4096

Response length limit. One token is roughly 3/4 of a word. 256 = very short responses (~190 words). 2048 = normal responses (~1500 words). 4096 = long responses (recommended). 8192 = practical maximum with 16 GB of RAM. More tokens = more time and more memory.

0.95

Limits which words the model considers when generating. With 0.95 (recommended by Google), the model chooses among words that sum up to 95% probability, discarding the rarest ones. Lowering to 0.5-0.7 makes responses more conservative. Raising to 1.0 allows any word (more variety).

Maximum number of candidate words at each generation step. 64 = recommended by Google. The model chooses among the 64 most probable words. 1 = always picks the most probable (very rigid). 0 = no limit (combined with top-p for filtering). Useful for controlling variety alongside temperature.

1.0

Penalizes the model for repeating the same words or phrases. 1.0 = no penalty (recommended by default). 1.1-1.2 = gently reduces repetitions. 1.5+ = aggressively avoids repetitions, but may break coherence. Only increase if you notice the model repeating itself a lot.

General instructions the model follows throughout the conversation. Here you define its "personality", language, response format, etc. It is sent as an invisible first message before each of your questions. Leave empty to use the model's default behavior.
