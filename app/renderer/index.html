Ajustes del modelo

Cuando esta activado, Gemma "piensa en voz alta" antes de responder. Razona paso a paso internamente y luego da una respuesta mas elaborada. Util para problemas de logica, matematicas o codigo. Desactivalo si solo quieres respuestas rapidas y directas.

1.0

Controla lo "creativa" o "aleatoria" que es la respuesta. 0.0 = siempre la misma respuesta, muy predecible. 0.3-0.5 = ideal para codigo y datos exactos. 0.7-1.0 = conversacion natural (recomendado por Google: 1.0). 1.5-2.0 = muy creativo, pero puede desvariar.

4096

Limite de longitud de la respuesta. Un token son unas 3/4 partes de una palabra. 256 = respuestas muy cortas (~190 palabras). 2048 = respuestas normales (~1500 palabras). 4096 = respuestas largas (recomendado). 8192 = maximo practico con 16 GB de RAM. Mas tokens = mas tiempo y mas memoria.

0.95

Limita las palabras que el modelo considera al generar. Con 0.95 (recomendado por Google), el modelo elige entre las palabras que suman el 95% de probabilidad, descartando las mas raras. Bajarlo a 0.5-0.7 hace respuestas mas conservadoras. Subirlo a 1.0 permite cualquier palabra (mas variedad).

Numero maximo de palabras candidatas en cada paso de generacion. 64 = recomendado por Google. El modelo elige entre las 64 palabras mas probables. 1 = siempre elige la mas probable (muy rigido). 0 = sin limite (se combina con top-p para filtrar). Util para controlar la variedad junto con temperatura.

1.0

Penaliza al modelo por repetir las mismas palabras o frases. 1.0 = sin penalizacion (recomendado por defecto). 1.1-1.2 = reduce repeticiones suavemente. 1.5+ = evita repeticiones agresivamente, pero puede romper la coherencia. Solo subelo si ves que el modelo se repite mucho.

Instrucciones generales que el modelo sigue en toda la conversacion. Aqui defines su "personalidad", idioma, formato de respuestas, etc. Se envia como primer mensaje invisible antes de cada pregunta tuya. Dejalo vacio para usar el comportamiento por defecto del modelo.
